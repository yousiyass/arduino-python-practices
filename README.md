## 🔌 Arduino & Python Integration Projects

Hi there! I'm an Electrical-Electronics Engineering student, and this section is a collection of my early hardware-software integration experiments. 

The projects here aren't overly complex, but they share a very important foundational theme: getting a computer to talk to physical electronics. 

**The General Architecture:**
* **Python (Host):** Runs on the PC to fetch real-time data, process information, and send it over the COM port.
* **Arduino (Device):** Receives the data via Serial (UART) and uses it to drive physical components like LCD screens, LEDs, or buzzers.

These are my practical experiments in learning serial communication, string parsing, and basic system logic. Feel free to check out the code and the hardware setups!
